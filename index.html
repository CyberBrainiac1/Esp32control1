Quick start

Connect without typing an IP

  1. Upload the included ESP32 sketch.
  2. On your iPhone, join Wi-Fi network ESP32-Control.
  3. Come back here and tap Auto connect to ESP32.

Add to Home Screen

On iPhone, Safari does not allow a website to add itself automatically. Tap Share → Add to Home Screen → Add. This button keeps the steps here so it is easy to follow.

Wi‑Fi is the best iPhone option: the ESP32 creates hotspot ESP32-Control at http://192.168.4.1, and the Auto connect button fills that in for you.

Bluetooth uses Web Bluetooth, which works in Chrome/Edge on supported devices. Safari on iPhone currently does not expose Web Bluetooth to websites, so use Wi‑Fi there.
